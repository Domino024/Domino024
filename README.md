## 🌟 Featured Professional Projects

### 🤖 Enterprise AI Chat Agent — Kalyani Motors

- Designed and deployed a production-ready WhatsApp AI chatbot and Admin Dashboard.
- Implemented lead capture and inventory management workflows.
- Enabled dynamic car search and test-drive booking.
- Automated customer interactions and reduced manual coordination.

**Technologies:** Gemini, Python, REST APIs, WhatsApp, AI Chatbots, Backend Integration

### 🎙️ Insurance Calling AI Agent

- Developed AI-powered inbound and outbound insurance calling agents.
- Integrated telephony APIs with LLM reasoning and STT/TTS systems.
- Implemented automated post-call processing and transcript summarization.
- Stored call transcripts and summaries in structured MySQL tables for supervisor review and auditing.
- Orchestrated multi-step AI workflows for customer interaction, backend data retrieval, and automated decision-making.

**Technologies:** Python, LLMs, STT/TTS, Twilio, Exotel, Tata Tele, MySQL

### 🧠 Domain-Specific LLM Fine-Tuning for Insurance Voice Agents

- Fine-tuned the Qwen3-4B language model using QLoRA and Unsloth.
- Prepared custom multi-turn conversational datasets for insurance workflows.
- Applied parameter-efficient fine-tuning to reduce GPU memory requirements.
- Evaluated and deployed the fine-tuned model for domain-aware conversational responses.

**Technologies:** Qwen3-4B, QLoRA, LoRA, Unsloth, Python, HuggingFace

### 📄 Enterprise Regulatory Reporting RAG Assistant

- Developed an enterprise-grade RAG assistant for PDF-based question answering.
- Implemented PDF ingestion, semantic chunking, embedding generation, and vector indexing.
- Integrated Gemini 2.5 Flash Lite, LangChain, Gemini Embeddings, and FAISS.
- Designed structured JSON responses and audit-traceable retrieval workflows.

**Technologies:** Gemini, LangChain, FAISS, RAG, Python, PDF Intelligence

### 🔍 Industrial Component Semantic Retrieval System

- Built an end-to-end semantic retrieval pipeline for Bill of Materials (BOM) queries.
- Used TinyLlama, FAISS, and fine-tuned MiniLM embeddings.
- Applied SimCSE-style contrastive learning to improve semantic retrieval.
- Designed a local inference pipeline using HuggingFace Transformers and PyTorch.

**Technologies:** TinyLlama, FAISS, MiniLM, SentenceTransformers, PyTorch

### 🚗 AI Service Car Chatbot

- Built a WhatsApp AI chatbot for car service inquiries, bookings, pricing, and offers.
- Integrated Gemini for intelligent reasoning.
- Implemented human handoff for complex customer queries.
- Developed a live agent dashboard to support customer service operations.

**Technologies:** Gemini, Python, WhatsApp, REST APIs, AI Automation
